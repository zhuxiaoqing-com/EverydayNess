4.切换地图流程;其实也就是游戏玩法基础流程;

    切换地图流程
        1. Client 请求切图
           Client -> Gate -> MapA

        2. MapA 本地锁玩家
           player.state = TRANSFERING_OUT
           transferId = newId

        3. MapA 请求 Location 开始迁移
           Location.BeginTransfer(roleId, MapA, transferId)

        4. MapA 生成 TransferSnapshot

        5. MapA 保存玩家永久数据到 DB
           Save PlayerData
           Save lastMapId / lastPosition

        6. MapA 发送快照给 MapB
           MapB.TransferIn(snapshot)

        7. MapB 创建玩家
           player.state = TRANSFERING_IN
           初始化 Unit / AOI / 坐标 / Buff / CD

        8. MapB 完成 Location 迁移
           Location.CompleteTransfer(roleId, MapA, MapB, transferId)

        9. MapB 通知 Gate 改路由
           Gate.ChangeRoute(roleId, MapB)

        10. MapB 激活玩家
           player.state = NORMAL
           下发 TransferComplete / 场景信息

        11. MapB 通知 MapA 删除旧玩家
           MapA.RemovePlayer(roleId, transferId)
